# BLS Refrigeração · Atendimentos

App (celular dos técnicos) e site para registro de atendimentos Carrier.

- `index.html` — o app completo
- `sw.js` — atualização automática / funcionamento offline (altere `VERSAO` a cada publicação)
- `manifest.webmanifest` e `icons/` — instalação na tela inicial

Publicado via GitHub Pages (Settings → Pages → Branch `main`, pasta `/root`).
